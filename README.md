# Breakout

A simple recreation of the classic Breakout game made as a hobby project using **C++** and **Raylib**.

I built this project to practice game development concepts like game loops, collision detection, object movement, and handling multiple game objects.

## Controls

* **Left Arrow** — Move paddle left
* **Right Arrow** — Move paddle right

## Built With

* C++
* Raylib

## Features

* Paddle movement
* Ball physics
* Brick collision and destruction
* Score system
* Lives system
